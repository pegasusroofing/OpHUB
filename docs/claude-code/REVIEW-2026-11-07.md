## Fixed tonight (Finance)
- **Decimals on invoice lines:** typing 12.50 in a price had become 1250, so a £12.50 line would have saved as £1,250. Boxes now keep what you type. The PO split % had the same problem; also fixed.
- **Tabbing past a drop-down:** Tab or Enter on an empty drop-down picked its first option. On the list, that could approve an invoice or set a job nobody chose. Now a drop-down only picks after you type or use the arrow keys.
- **Approve from the list:**
  - it now asks first;
  - Approve on an emailed invoice waits until the price lists and PO have loaded, so the "dearer than…" warning still shows.
- **Approve links:** the action no longer rides in the link, so a link someone pastes can't approve anything just by being opened (security review).
- **Reject from the list:** warns when the invoice is already in Xero, and says if it didn't save.
- **Flagged invoices:** a query flagged when saving stays in **Needs Checking**. **With A PM** now holds only ones a PM (or the supplier) was actually asked about.
- **Query Supplier:**
  - it undoes "approves itself", like Save does;
  - on an emailed invoice it only shows once there's a job.
- **Old ✕ reasons** by a PO are cleared when the invoice is fixed and saved.
- **Cancel Edit** goes back to the saved lines.
- **"Who was asked"** looks at the newest message.
- **Table width:** the Approved / All table fits a laptop again.
